# NN Paper Reproduction

This repository contains simplified reproductions of three lightweight CNN image classification papers.

## Papers

1. DualConv: Dual Convolutional Kernels for Lightweight Deep Neural Networks
2. EfficientNetV2: Smaller Models and Faster Training
3. Lightweight image classifier for CIFAR-10
